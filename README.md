# 📷 レシート日本円変換

海外旅行や海外出張で受け取ったレシートを撮影・読み込みして、自動で日本円に変換・記録できるアプリです。スマホやパソコンのブラウザだけで使えます（インストール不要）。

**アプリを開く**: https://tomohirokitagawa.github.io/receipt-jpy-converter/
**視覚的な利用ガイド（図解版）**: https://tomohirokitagawa.github.io/receipt-jpy-converter/guide.html

## できること

- レシートの写真を選ぶだけで、店名・日付・通貨・金額をOCR（自動文字認識）で読み取ります
- 読み取った金額を、その日の為替レートで自動的に日本円に変換します
- 内容を確認・修正してから履歴として保存できます
- 保存した履歴から、確定申告（freee会計）にそのまま取り込めるCSVファイルを出力できます
- 一度開いたらオフラインでも動作します（スマホのホーム画面に追加してアプリのように使うこともできます）

## 使い方（基本操作）

1. **画像を選ぶ**
   「📁 画像を選択 / 撮影（複数可）」を押して、レシートの写真を選びます。複数枚まとめて選ぶこともできます。
2. **読み取る**
   「🔍 まとめて読み取る」を押すと、画像の内容を自動で読み取ります（少し時間がかかります）。
3. **内容を確認・修正する**
   読み取り結果が下に表示されます。店名・日付・通貨・品目・金額が間違っていたら、直接タップして修正してください。
   - 「＋ 行を追加」で品目を追加できます
   - 「✕」で不要な行を削除できます
4. **日本円への換算を確認する**
   「日本円 換算」欄に、その日のレートで換算した金額が表示されます。
5. **保存する**
   内容が正しければ「💾 このレシートを保存」を押して履歴に保存します。不要な場合は「🗑 破棄」で削除できます。
6. **履歴を見る**
   画面下の「履歴」セクションで、保存したレシートの一覧を確認できます。タップすると品目の詳細が開きます。不要な履歴は「削除」で消せます。

## 自動読み取りモード

「自動読み取りモード」のチェックボックスをオンにしておくと、画像を選んだ瞬間に自動で読み取りが始まります。「🔍 まとめて読み取る」を毎回押す手間を省けます。

## 確定申告用CSV出力（freee会計）

履歴セクションの下部「確定申告用CSV出力」から、保存したレシートをfreee会計にそのまま取り込める形式（CSV）で出力できます。

1. レシートを保存する際、「勘定科目（freee用）」で該当する項目（旅費交通費・会議費など）を選んでおきます
2. 履歴セクション下の「開始日」「終了日」で出力したい期間を指定します
3. 「⬇️ freee用CSVを出力」を押すとCSVファイルがダウンロードされます
4. freee会計の「取引の取り込み」機能で、ダウンロードしたCSVを取り込んでください

※ 為替レートが確定していないレシート（換算に失敗したもの）は出力対象から除外されます。除外があった場合は件数がメッセージで表示されます。

## レシートの日付とレート換算について

- レシートの「日付」が**今日**の場合は、現在の為替レートで換算します。
- 日付が**今日以外**の場合は、その日付時点の為替レート（歴史的レート）を自動で取得して換算します。日付を変更すると、レートも自動で再取得されます。
- 一部の通貨（例: ベトナムドン、台湾ドルなど）は日付ごとのレートに対応していません。この場合は「（日付未対応のため現在レートを使用）」と表示され、現在のレートで換算されます。

## よくある質問・困ったとき

**Q. アプリを更新したのに、新しい機能が表示されない**
A. 一度ブラウザのタブを閉じて、少し時間を置いてから開き直してください（Windows/Chromeなら `Ctrl+Shift+R` で再読み込みするのも有効です）。このアプリはオフラインでも使えるようにする仕組み上、更新の反映に少し時間がかかることがあります。

**Q. 読み取り結果が正しくない**
A. OCR（自動文字認識）は完璧ではありません。店名・日付・通貨・金額は保存前に必ず確認し、間違っていれば直接修正してください。

**Q. 通貨が違う結果になっている**
A. 「通貨（レシートの通貨）」欄を直接編集すれば、正しい通貨コード（例: USD、EUR）に変更できます。

**Q. データはどこに保存されるの？**
A. すべてこの端末のブラウザ内（localStorage）に保存されます。外部のサーバーには送信されません。ブラウザのデータを消去すると履歴も消えるのでご注意ください。
